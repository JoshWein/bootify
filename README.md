# bootify
Chrome Extension that injects bootstrap style into any page.

Chrome Store: https://chromewebstore.google.com/detail/ekbicbimdmfoehanpahkcajejciloahj (needs re-publishing as Manifest V3)

To try it locally: open chrome://extensions, turn on Developer mode, click "Load unpacked" and pick this folder.

## How to use
*  Go to the options to add a website for the extension to run on automatically or right-click the extension or the page to add or remove the current page from the list.
